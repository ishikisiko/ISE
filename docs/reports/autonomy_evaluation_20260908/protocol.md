# ISE 自主度两轮真实评测协议

日期：2026-09-08。用户授权：完成真实对比 → 分析 → 一轮修改 → 真实复测 → 完整报告；随后独立交付 devbench T04/T03 题目适用性分析与扩展。

## 固定口径

- 第一轮使用当前主线产品实现（`76d1b98`），仅先修复 baseline runner 的参数接线。第二轮只纳入第一轮分析后确定的一组产品改动；两轮分别保留源码文件摘要、补丁与配置摘要。
- 启动检查发现 OpenCode Go 现要求会话路由标识：原始 `autonomy-20260908/r1` 的首对请求均返回 HTTP 400 `MissingSessionID`，不构成模式质量对比。保留该预检查队列和失败；先为两种客户端与辅助模型补齐不含用户原始标识的 `x-opencode-session` 与真实 `ISE/1.0` User-Agent，依照 [provider 接入文档](https://opencode.ai/docs/go/#where-can-i-use-it)。正式两轮在 `autonomy-20260908-live` 中重新冻结，使用相同兼容修复。
- 第二次首对启动检查（`autonomy-20260908-live/r1`）确认 `_act_shim` 丢弃 usage，主模型调用未进入应用 token 总数。正式两轮因此统一采用 `autonomy-20260908-measured`，评测侧旁观 HTTP 响应的 usage，不修改应用请求/返回；原应用统计与独立 transport 统计同时保留。两组启动检查均不进入主要比较，不挑选其中较好答案。正式评分模型固定为 `glm-5.2`，不用 DeepSeek 的 `thinking=disabled` 参数（GLM 拒绝该取值）；原生默认 reasoning 接入 smoke 已通过。
- 全部 20 道 `final_answer_dataset.csv` 和 20 道 `open_task_dataset.csv`，guided / autonomous 各运行一次：每轮 80 条，两轮 160 条。相邻调度同一道题的两模式，顺序按题交替；第二轮反转顺序。重复数 1，不宣称统计显著性或普适优越性。
- 使用当前配置的 `opencode-go/deepseek-v4-flash`，保留各场景既有模型、reasoning 与搜索配置；两模式请求参数一致：搜索结果数 5、回答输出上限 4000、temperature 0.2。若服务不可用，先记设施失败并核实原因，不静默换模型或删除失败。
- 并发最多 2 个查询进程，各查询使用独立 checkpoint、audit 和空上传目录，避免用户文档与会话污染。真实网络及 provider 调用；不使用 mock 代替真实结果。查询软截止 600 秒，在节点边界取消；660 秒仍未退出则停止该独立进程组，记 `harness_timeout`。保留失败，不自动重跑产品失败以挑选高分。
- 每条完成即以独占创建方式写入结果；恢复只跳过已有结果，不覆盖。运行清单包含完整计划，未完成条目不能在汇总中消失。应用 token 以实际捕获值记账，缺失/不完整明确标注；不将 token 当费用，未获得账单/定价绑定的 USD 为 null。评审模型调用单独记账。

## 质量与评审

- 兼容指标：原有 `fact_coverage`（英文关键词重叠），保留原值，但它不验证事实正确性、同义表达、中文答案或引用支持，不能独自承担安全性判定。
- 事实题：按核心回答正确性（0/1/2）、需求完成度（0/1/2）、证据支持（0/1/2）辅助复核。核心答案准确即可满足问题，不强求参考答案的所有额外细节。拒答/只给计划/空答不得算完成。
- 开放题：使用原 CSV 中四个 scoring_dimensions，每项 0–2；0=未满足/明显错误，1=部分、笼统或缺支撑，2=具体且满足需求。给出答复中可定位的理由，另记明显事实问题与证据支持情况。
- 辅助评审使用独立请求、隐藏模式与轮次标签，答案和取回的证据只作待评数据，不能给评审下指令。先验证配置中可用的另一模型 `glm-5.2`；若不可用，在开始正式评分前确定可用替代并记录。不允许评分后择优换裁判。
- 模型辅助评分不是真人评分，不作为 devbench 人工加分。报告保留 `human_review: not_performed`，并将 OpenSpec 原先要求真人评分的验收条件与本次用户授权的自动完成结果分别说明，不伪造人工签署。
- 事实参考勘误在看运行答案前固定：final016 的 August 1998 是投资时间，Google 公司注册为 1998-09-04，二者须区分；final002 中 Pluto 应称矮行星；final017 接受通常以尼罗河为最长并说明亚马逊测量争议。其他问题按问题本身的必需信息评分，不因参考答案额外细节缺失误判。

Google 自述页面把 August 的支票与公司诞生连写；其生日说明明确注册日期为 September 4：[Google 2018 说明](https://blog.google/company-news/inside-google/company-announcements/marking-20ish-years-google/)，[SEC 10-K 注册月份](https://www.sec.gov/Archives/edgar/data/1652044/000165204425000014/goog-20241231.htm)。木卫三大小口径参见 [NASA Ganymede](https://science.nasa.gov/jupiter/jupiter-moons/ganymede/)。原 CSV 不重写，勘误仅用于附加语义评审，原关键词分仍可复算。
